Важно: в Anomaly содержимое обычных тайников генерируется случайно. Карта показывает места, но не гарантирует конкретный набор предметов. Тайники, полученные по наводке, содержат лут. Поэтому фиксированный список предметов для каждого схрона был бы недостоверным.
