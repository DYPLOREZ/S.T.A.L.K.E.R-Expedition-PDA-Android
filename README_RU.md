# Expedition PDA — Android project v0.4

Русскоязычная горизонтальная оболочка КПК для Android.

## Что добавлено в v0.4
- Встроена предоставленная карта Anomaly Map Colour 3840×9788.
- Оригинал преобразован в локальную офлайн-пирамиду из 213 WebP-фрагментов с четырьмя уровнями детализации.
- Карта подгружает только видимые фрагменты; это снижает пиковое потребление памяти при перемещении и приближении.
- Добавлена адаптивная иконка приложения с символом радиации.
- Горизонтальная ориентация Android закреплена.

## Важно о данных
На предоставленной карте уже видны цветные отметки, но в проекте пока нет подтверждённой базы координат Expedition 2.3 для названий локаций, тайников и аномалий. Массивы `areas`, `stashes`, `anomalies` намеренно пустые. Не добавляйте приблизительные координаты как реальные.
Проверить соответствие самой карты именно Expedition 2.3 также ещё предстоит.

## Координатная система
Координаты объектов задаются нормализованными x/y от 0 до 1 относительно исходной карты 3840×9788. Маркеры должны размещаться в мировых координатах, а не в экранных.

## Сборка
Откройте проект в Android Studio и выполните Build > Build APK(s), либо используйте GitHub Actions workflow с `gradle assembleDebug`.
