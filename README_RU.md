# Expedition PDA — Android project

Android-проект КПК для S.T.A.L.K.E.R. Anomaly / Expedition 2.3.

## Что уже есть
- Русский интерфейс в стиле КПК.
- Вкладка с интерактивной community-картой (Fandom; интернет обязателен).
- Ссылки на опубликованную карту Anomaly со схронами и русское руководство по тайникам.
- Отдельная вкладка для аномальных полей с пояснением о нехватке проверенной публичной карты.
- Личные метки: пользователь может записывать тайники/аномалии, описание и содержимое.
- Статус личной метки меняется с серого на зелёный после открытия карточки.
- Сохранение заметок локально на устройстве.

## Честные ограничения данных
Карта схронов из Reddit — community-карта Anomaly, а не гарантированная карта Expedition 2.3. В опубликованной теме автор прямо пишет, что поля аномалий не были доступны для автоматического отображения и их пришлось бы отмечать вручную.
В Anomaly содержимое обычных тайников рандомизируется и может меняться со временем. Поэтому приложение не приписывает каждому схрону выдуманный фиксированный лут. Сейчас внешняя карта отображается внутри WebView, а собственные интерактивные записи хранятся локально.

## Сборка APK
Открой папку в Android Studio, затем запусти `app` → `assembleDebug`. APK появится в `app/build/outputs/apk/debug/app-debug.apk`.
Либо отправь проект в GitHub и запусти workflow `Build Android APK` из `.github/workflows/android.yml`.
